# Dockerfile + Flask

Пример приложения Flask, которое можно развернуть с помощью Dockerfile без настройки.

## Параметры деплоя

| Поле | Значение |
| --- | --- |
| Сборка | Dockerfile |
| Путь до директории проекта | `/` |
| Порт приложения | `3478` |
| Путь проверки состояния | `/` |

Образ собирается по `Dockerfile` из корня репозитория. В контейнере работает gunicorn на порту из
переменной окружения `PORT` — её передаёт платформа, — а без неё `3478`. В образ поставлен `curl`:
проверку состояния платформа выполняет внутри контейнера через `curl` или `wget`.

## <a name="dev"></a>Локальный запуск проекта

```bash
# сборка docker образа
docker build -t dockerfile-flask-app:latest .

# запуск контейнера на порту 3478
docker run -d -p 3478:3478 dockerfile-flask-app
```
